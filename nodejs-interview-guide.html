⚡ Interview Tips
01
Always explain the event loop visually. Draw or describe the call stack → microtask queue → macrotask queue flow. Interviewers love seeing you trace through a mixed Promise + setTimeout snippet step-by-step.
02
Know when NOT to use Node.js. CPU-intensive tasks (video encoding, ML inference) block the event loop. Mentioning Worker Threads or offloading to a separate service shows architectural maturity.
03
Connect answers to real projects. "In my ERP system I used streams to export 50,000+ records as CSV without loading everything into memory" beats a textbook definition every time.
04
Discuss error handling strategies. Unhandled promise rejections, domain errors, process-level uncaughtException — covering all layers signals production experience.
05
Security is a differentiator. Mention rate limiting, helmet.js, input validation, OWASP Top 10, and dependency audits unprompted in architecture questions — most candidates skip this entirely.
06
For scenario questions, use STAR. Situation → Task → Action → Result. Structure your answer, mention the trade-offs you considered, and quantify outcomes where possible (e.g. "reduced response time by 40%").
